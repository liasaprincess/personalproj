# HEX Color Tool

A small, dependency-free browser app for previewing HEX colors. It uses plain HTML, CSS, and JavaScript.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Enter a six-digit HEX value such as `#6C63FF`, then select **Preview**.

No build step, package manager, or external dependencies are required.

## Current starter functionality

- Six-digit HEX input with or without the `#` prefix
- Color preview
- Basic invalid-input message
- Enter-key submission

## Suggested extension task

Improve the app to support three-digit and six-digit HEX values, live preview, HEX-to-RGB conversion, copy controls, clearer validation, and a reset action. Preserve the existing project structure and avoid unnecessary dependencies.
