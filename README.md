# MY OS — Personal Web Operating System

A browser-based personal operating system shell.

## Run it
Open `index.html` in a modern browser.

## Included in V1
- Futuristic monochrome desktop
- Sidebar navigation
- App launcher
- Dock
- Clock and date
- Dashboard widgets
- Notes saved to browser localStorage
- Tasks
- Files, Projects, Calendar, Finance, Assistant, Settings placeholders
- Draggable app windows
- Responsive mobile layout
- Command/search shortcut: Ctrl+K (Cmd+K on Mac)

## Next upgrades
Connect a real database/authentication layer, cloud files, calendar APIs, AI assistant, notifications, and installable PWA support.
